## 3. feat/native-mm-sfx — EXACTLY where the audio agent left off

**Goal (owner):** MM's form sounds play NATIVELY in OOT's own audio engine (one mixer, zero added latency), like
sm64coopdx character sound banks — reading MM's data from MM's resident ResourceManager. Option A (chosen after an
exploration): host MM's real `Sequence_0` (MM's sfx sequence) on a 5th OOT sequence player whose channels/layers run a
port of MM's seqplayer dialect; MM's sfx request front-end ported into OOT; MM ids played verbatim.

**Why a port and not "just load the data":** MM's soundfont/sample structs are layout-identical to OOT's, but MM's
seq-0 scripts use opcodes OOT's seqplayer lacks (channel 0xA0–0xA8 sfxState/bit ops/random, 0xBE custom function,
layer 0xF0/0xF1, seq 0xC2/0xC3; MM's arg table starts at 0xA0), MM routes per-sfx freqScale/pan/filter through
`SfxChannelState`, MM's io5 encoding differs, MM's SFX_INDEX is 10 bits.

**Files (21 changed, +4732/−168 vs `4bd5c6f2`):**
- `soh/src/code/audio_seqplayer_mm.c` (+1995, new) — port of MM `mm/src/audio/lib/seqplayer.c` (MM dialect) for the
  MM player.
- `soh/src/code/audio_mm_sfx.c` (+1665, new) — port of MM's sfx front-end (`mm/src/audio/sfx.c` + parts of
  `code_8019AF00.c`: request queue, bank/channel layout, MM io encoding, SfxChannelState, AudioSfx_SetProperties,
  custom function 0).
- `soh/src/code/audio_mm_sfx_params.c` (+84, new) — MM SfxParams tables (built from mm/include/tables/sfx/*.h — code,
  not ROM data).
- `soh/soh/Enhancements/randomizer/ComboMmAudio.cpp` (+329, new) — registers MM `Sequence_0` + its fonts from MM's RM
  into OOT's sequenceMap/fontMap ("@mm:" routing), starts the 5th player.
- `soh/soh/ResourceManagerHelpers.cpp` (+34) — "@mm:" routing for audio resources (seq/font/sample) like
  `Combo_LoadRoutedAnim`.
- `soh/include/z64audio.h` (+30) — 5th seq player, MM fields appended to SequenceChannel etc.
- `soh/src/code/{audio_effects.c, audio_heap.c, audio_load.c, audio_playback.c, audio_seqplayer.c, code_800E4FE0.c,
  code_800EC960.c, code_800F7260.c}` — 4->5 player loops/limits, dispatch to MM dialect for the MM player, MM note
  features (gain etc.).
- `soh/soh/Enhancements/randomizer/ComboGuestAudio.cpp` (rewritten, +533/−) — keeps the old C API
