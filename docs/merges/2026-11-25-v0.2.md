## Survival checks (the 0.1.x line)

- **Pure merge:** `git diff --stat <merge-tree of upstream and pass2> fe293ecf3` lists only the three conflict files.
- **Per file:** for every file pass2 changed since `5c4ebf1e7`, the patch-id of pass2's diff matches the merge's. Of
  116 files, six differ: the three conflict files; `GameInteractor_VanillaBehavior.h` and `mm/src/code/z_player_lib.c`,
  where upstream made the same `isDpad` change; and `z_arms_hook.c`, where only a context line changed. The same check for
  the discord and back2back merges differs only in their conflict files, plus `ComboOwlWarp.cpp` (the same change with
  different context lines).
- **Feature probes:** a fixed list of symbols and CVars from every 0.1.x feature keeps its count through all three merges.
  Five counts changed, each for a known reason. The list is in the work folder's 0.2.0 plan.

## Saves

`COMBO_RELEASE_VERSION` 0.4.0 retires 0.1.x save containers. Each is renamed once to
`fileN.combosav-<time>.bak`, with a notice. `Save/backups/` (made at every launch), the co-op outbox and presets are not
touched. A 0.1.x build would in turn retire a 0.2.0 save, so 0.2.0 runs from its own folder.
